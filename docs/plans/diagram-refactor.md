# 形式ごとの入口とソース検証の実装

## 目的と範囲

図の内容・図の表現・閲覧の場を同じリポジトリ内で分離する。
Mermaid と Onion の形式定義・検証・描画入口を形式ごとにまとめる。
Onion の JSON Schema・書式・サンプルを公開し、CLI と描画が同じ解析・検証を使う。
CLI にローカルファイルの検証と表示用 URL を返す入口を追加する。
診断はファイル、JSON Pointer、コード、メッセージを JSON で返し、不正時は非ゼロ終了する。
既存の一覧・編集・保存・更新検知・選択を維持する。
VPD の新規対応、SVG 入力、外部パッケージ化は含めない。

## 検証

- 正常な単一・複数コンテキストの CLI 検証と描画。
- JSON 構文、型、バージョン、ID 重複、未定義参照の診断と CLI 終了コード。
- CLI のファイル表示から HTTP 取得・外部更新反映まで。
- 公開 Schema とサンプルの整合性、形式登録とブラウザ配信。
- 既存テスト全体、Docker 起動、ブラウザで Mermaid と Onion の表示・選択・更新を確認。
- wsl-preview に七日期限のレビュー用アプリを公開する。

## 状態

実装済み。形式の公開入口を `formats/*/format.mjs` と `formats/index.mjs` に集約した。
Onion の Schema・構造化診断・正規化・配置・描画・CSS を分離し、Mermaid も同じ入口にそろえた。
CLI に `validate`、`show`、`formats`、`schema` を追加した。

検証結果:
- Node 22 のコンテナでテスト全体を実行。CLI と描画の診断一致、正常・不正サンプル、単一ファイルの HTTP/SSE、描画器の読み込み競合を確認。
- 公開 Schema と生成済み検証器の一致を `npm run check:onion-schema` で確認。
- Docker ビルド成功。開発依存を除いた非 root・読み取り専用環境でも Onion/Mermaid の CLI 検証が成功。
- 実ブラウザで Mermaid と Onion の一覧・詳細、Onion の選択・強調、参照エラーと修正後の回復、外部更新の自動反映を確認。
- レビュー用プレビューを `wsl-preview` の7日期限で公開。
- 文書リンクと差分の空白を確認。

VPD、SVG 入力、要素からソースを開く共通 UI、表示版の追跡は今後の別変更。
