# 形式ごとの入口とソース検証の実装

## 目的と範囲

図の内容・図の表現・閲覧の場を同じリポジトリ内で分離する。
Mermaid と Onion の形式定義・検証・描画入口を形式ごとにまとめる。
Onion の JSON Schema・書式・サンプルを公開し、CLI と描画が同じ解析・検証を使う。
CLI にローカルファイルの検証と表示用 URL を返す入口を追加する。
診断はファイル、JSON Pointer、コード、メッセージを JSON で返し、不正時は非ゼロ終了する。
既存の一覧・編集・保存・更新検知・選択を維持する。
VPD の新規対応、SVG 入力、外部パッケージ化は含めない。

## 検証

- 正常な単一・複数コンテキストの CLI 検証と描画。
- JSON 構文、型、バージョン、ID 重複、未定義参照の診断と CLI 終了コード。
- CLI のファイル表示から HTTP 取得・外部更新反映まで。
- 公開 Schema とサンプルの整合性、形式登録とブラウザ配信。
- 既存テスト全体、Docker 起動、ブラウザで Mermaid と Onion の表示・選択・更新を確認。
- wsl-preview に七日期限のレビュー用アプリを公開する。
